Vehicle Customs

Version — 2.3.0 Requires — QBCore, oxmysql, ox_target (optional) Updated — July 2026

Overview

Vehicle Customs adds a full paint, wrap, and performance customization menu for player-owned shops — colors, liveries, wheels, tint, neon, and bolt-on performance upgrades, all synced to the vehicle's persisted mods.

Installation

  1. Drop the ds-vehiclecustoms folder into your server's resources directory.
  2. Add ensure ds-vehiclecustoms to your server.cfg, below your framework and oxmysql.
  3. Import install.sql to add the shop-ownership table.
  4. Restart the resource or the server.

Configuration

Open config.lua and set the shop locations and pricing tiers for your server.

Config.Locale = 'en'
Config.UseTarget = true -- set false to use a marker + E interaction instead
Config.Shops = {
    { coords = vector3(-196.6, -1308.5, 31.3), label = 'Downtown Customs' },
}

Commands & permissions

  • /opencustoms — staff-only command to open the menu anywhere for testing.
  • Shop ownership is checked against the table added by install.sql; grant access via /grantshop [citizenid] [shopId].

Troubleshooting

If the menu doesn't open, confirm ox_target is started before this resource when Config.UseTarget is true. If mods don't persist, double-check install.sql was imported into the same database your framework uses.

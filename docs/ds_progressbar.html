DS Progressbar

Standalone cinematic progress bar — corner brackets, color presets, cancellable — by DS Customs

v1.0.0 QBCore FiveM Lua 5.4 No SQL

1 — Overview

DS Progressbar is a single, self-contained progress bar resource. Any other resource on your server can start a cinematic progress bar via a clean export API — label, duration, color preset, optional percentage counter, and an optional X-to-cancel button. The result is always returned through a Lua callback.

DS Progressbar ships with the same 4-corner bracket visual language as DS Notify — both resources share an identical color palette so they always look like they belong together.

2 — Installation

  1. Place the ds_progressbar folder inside your resources directory.
  2. Add ensure ds_progressbar to your server.cfg before any resource that depends on it.
  3. Done — no SQL, no further configuration required.
# server.cfg
ensure ds_progressbar
ensure ds_notify        # optional companion — same visual language
ensure my_job_resource  # any resource that uses ds_progressbar
To declare the load-order dependency in another resource, add dependency 'ds_progressbar' to that resource's fxmanifest.lua.

3 — Configuration — config.lua

config.lua is open and unencrypted. Every setting here is a fallback used when a caller does not pass that option to Start().

-- Fallback size when none is passed to Start()
Config.DefaultSize = 'medium'

-- Fallback color preset when none is passed to Start()
Config.DefaultColor = 'blue'

-- Allow the player to press X to cancel any active bar
Config.AllowCancel = true

-- Text shown in the cancel hint below the bar
Config.CancelKeyLabel = 'X'

-- Vertical position on screen
Config.Position = 'lower'

-- Show a live xx% counter at the right of the label row
Config.ShowPercent = false

Config.Position values

ValueDescription
'lower'Lower-third of the screen, above the hotbar area (default)
'center'Classic dead-center of the screen

Config.DefaultColor presets

ValueCorner & bar color

'red'Danger / EMS red
'green'Success / medical green
'gold'VIP / money gold
'purple'Gang / dark-ops purple
'teal'Hacker / tech teal
'orange'Mechanic / service orange
'white'Clean / minimal white

4 — Start(opts, callback)

Starts a progress bar. If a bar is already active the callback fires immediately with cancelled = true and nothing is shown.

Options table

KeyTypeRequiredDefaultDescription
labelstringNo'Working...'Text shown above the bar.
durationnumberNo3000Bar fill time in milliseconds. Minimum 100.
sizestringNoConfig.DefaultSize'small', 'medium', or 'large'.
colorstringNoConfig.DefaultColorAny color preset name — see §3.
percentbooleanNoConfig.ShowPercentShow live percentage counter.

Callback

function(cancelled)
    -- cancelled = true  → player pressed X or Stop() was called externally
    -- cancelled = false → bar completed naturally
end

Examples

-- Minimal — all defaults
exports['ds_progressbar']:Start({
    label    = 'Picking lock...',
    duration = 5000,
}, function(cancelled)
    if cancelled then return end
    -- lock was picked
end)

-- Full options
exports['ds_progressbar']:Start({
    label    = 'Hacking terminal...',
    duration = 12000,
    size     = 'large',
    color    = 'teal',
    percent  = true,
}, function(cancelled)
    if cancelled then
        -- player cancelled
        return
    end
    -- hack complete
end)

5 — Stop()

Force-cancels the active bar from outside. The callback of the active bar fires with cancelled = true. Safe to call even when no bar is running.

-- Force-stop from another resource or event handler
exports['ds_progressbar']:Stop()
Use Stop() to cancel a bar when an external condition is met — e.g. the player enters a vehicle, gets downed, or a server event fires.

6 — IsActive()

Returns true if a bar is currently running, false otherwise. Use this to guard against starting a second bar while one is already active.

if not exports['ds_progressbar']:IsActive() then
    exports['ds_progressbar']:Start({ label = 'Reloading...', duration = 2000 }, callback)
end

7 — Quick Reference

ExportSignatureReturns
Startexports['ds_progressbar']:Start(opts, callback)void
Stopexports['ds_progressbar']:Stop()void
IsActiveexports['ds_progressbar']:IsActive()boolean
All three exports are client-side only. There are no server-side exports — the progress bar is a pure client UI.

8 — File Structure

ds_progressbar/
├── fxmanifest.lua     ← Resource manifest
├── config.lua         ← Defaults for size, color, cancel, position (open, editable)
├── client/
│   └── main.lua       ← Start(), Stop(), IsActive() exports + cancel key thread
└── html/
    ├── index.html     ← NUI root — widget with corner brackets
    ├── style.css      ← All visual styles — color tokens, size presets, animations
    └── script.js      ← NUI message handler; drives bar fill, spark, percent counter

9 — Notes

  • Only one bar can be active at a time. A second Start() call while a bar is running fires the new callback immediately with cancelled = true and does nothing visually.
  • All options are optional — Start({}, callback) is valid and uses the config defaults.
  • duration has a minimum of 100 ms. Values below this are clamped.
  • The cancel key (Config.CancelKeyLabel) only works when Config.AllowCancel = true. You can disable cancelling per-server by setting this to false.
  • DS Progressbar has no database calls and no QBCore dependency of its own. It is purely a client UI layer.
  • The resource is Escrow-protected except for config.lua, which is fully open.

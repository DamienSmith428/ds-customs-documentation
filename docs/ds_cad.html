DS CAD

In-world 3D police Computer-Aided Dispatch — a physical laptop mounted inside your patrol vehicle — by DS Customs

v1.0.0 Qbox QBCore ESX Lua 5.4 Escrow

1 — Overview

DS CAD spawns a physical laptop prop inside any law-enforcement vehicle and renders the CAD interface onto it as a live 3D DUI panel — powered by the CR3D (Cerulean 3D NUI) library. The panel follows the vehicle perfectly as it moves. Officers interact via a cursor that appears inside the 3D screen; the rest of the game world receives input normally.

The CAD feeds its data directly from DS MDT: active dispatch calls are pulled live via the GetActiveDispatchCalls export, and vehicle BOLO checks query GetVehicleBolo. DS CAD is the physical in-car companion to the DS MDT tablet.

This is a v1.0.0 beta release. Core systems are stable and production-ready. Additional features are actively being added.

4 — Installation

Database

DS CAD auto-creates its tables on first start via MySQL.ready. No SQL file needs to be imported manually.

TablePurpose
ds_cad_dataPersistent session data (call assignments and resolved calls) stored as JSON. Survives server restarts.
ds_cad_reportsArrest reports, citations, and other forms submitted from the CAD panel.

server.cfg Start Order

ensure oxmysql
ensure qbx_core        # or qb-core / es_extended
ensure ds_mdt          # must start before ds_cad
ensure ds_cad
DS CAD calls exports.ds_mdt:GetActiveDispatchCalls() and exports.ds_mdt:GetVehicleBolo() at runtime. If ds_mdt is not started first these calls will silently return nothing.

6 — Using the CAD In-Game

Opening the CAD

  1. Get in any vehicle.
  2. Run /cad. The laptop prop spawns on the passenger seat and the 3D panel appears on-screen.
  3. Press J (or your configured key binding) to enable cursor interaction. Your camera stops moving and a cursor appears on the panel.
  4. Click, scroll, and interact with the CAD UI normally.
  5. Press ESC or Backspace to exit cursor mode without closing the CAD.
  6. Run /cadclose to fully close and clean up.

CAD panels

PanelDescription
Unit StatusLive list of all online officers in authorised jobs, showing name, callsign, status (AVAILABLE / BUSY / UNAVAILABLE), and agency. Officers update their own status from the CAD.
Dispatch CallsActive calls pulled from DS MDT. Click a call to see details; click Assign to self-assign your unit; click Resolve to close the call.
Vehicle ScanCasts a ray forward from the vehicle. Returns plate, owner name, model, and BOLO status for the nearest vehicle in front.
RecordsBrowse and view the 50 most recent reports filed by any officer through the CAD.
File ReportSubmit a new report (arrest, citation, etc.) with custom form fields. Posted to the ds_cad_reports table and fired to the configured Discord webhook.

Edit mode

Run /cadedit while the CAD is open to enter edit mode. The laptop prop and panel can then be repositioned together:

KeysAction
← / →Move prop on the X axis.
↑ / ↓Move prop on the Z axis (up/down).
Num+ / Num-Move prop on the Y axis (forward/back).
Shift + arrow keysRotate the prop.
EnterPrint the updated coordinates to the F8 console. Copy them to the top of client/main.lua.
Hold Shift5× movement / 2× rotation speed modifier.
Edit mode is provided to let you dial in the prop placement for custom vehicles. Once you have the right values, paste them into the DASH_PROP_OFFSET and DASH_PROP_ROT globals at the top of client/main.lua (this file is escrow-excluded on request if needed).

7 — Developer API

Server Export

RefreshData()

Forces an immediate broadcast of the current officer list and active call list to all connected clients. Useful if you change officer data from another resource and want the CAD to reflect it without waiting for the next 1-second polling tick.

exports['ds_cad']:RefreshData()

Net Events — Server-side

ds_cad:updateStatus (status)

Fired by an officer to set their unit status. Valid values: "AVAILABLE", "BUSY", "UNAVAILABLE". Triggers an immediate data broadcast to all clients.

ds_cad:assignCall (callId)

Assigns the calling officer's unit (resolved from their callsign metadata) to the specified call. Also notifies DS MDT via exports.ds_mdt:AssignUnitToCall().

ds_cad:resolveCall (callId)

Marks a call as resolved. Persisted to ds_cad_data and forwarded to DS MDT via exports.ds_mdt:ResolveCall().

DS MDT event listeners

DS CAD automatically re-broadcasts updated CAD data whenever DS MDT fires these server-side events:

EventTrigger
ds_mdt:server:newCallA new dispatch call was created in DS MDT.
ds_mdt:server:updateCallAn existing dispatch call was updated.
ds_mdt:server:deleteCallA dispatch call was deleted.

8 — FAQ & Troubleshooting

The laptop prop doesn't appear when I run /cad

The prop model is streamed via /assetpacks. Ensure ensure /assetpacks is in your server.cfg above ds_cad. If the model still fails to load, the loadModel function has a 5-second timeout and will continue without the prop — the panel will still appear anchored to the vehicle.

/cad says "Access Denied: Authorized Jobs Only"

The player's framework job name must exactly match one of the entries in Config.Jobs. The check is case-sensitive. Verify the exact job name via QBCore.Functions.GetPlayer(source).PlayerData.job.name in the server console.

The 3D panel doesn't follow the vehicle correctly after I customise prop placement

After changing DASH_PROP_OFFSET / DASH_PROP_ROT and restarting the resource, re-open the CAD for the changes to take effect. The CR3D attachment is computed once per /cad open.

Dispatch calls aren't appearing on the CAD

DS CAD pulls calls via exports.ds_mdt:GetActiveDispatchCalls(). Make sure DS MDT is running and started before DS CAD. If there are no active calls in DS MDT there will be nothing to show.

Vehicle scans return "UNREGISTERED" for a vehicle I own

The scan queries player_vehicles (QB/QBX) or owned_vehicles (ESX) by the vehicle's number plate text. Ensure the plate on the in-game vehicle matches the plate stored in your database exactly, including any spaces.

Reports aren't posting to Discord

Check that Config.Webhook is set to a valid Discord webhook URL. The resource skips the POST if the value is an empty string. Also confirm the webhook channel is in a server where the webhook is still active.

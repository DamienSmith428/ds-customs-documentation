DS Prison Creator

Complete database-driven jail & prison creation, management, and sentencing system — all configured in-game — by DS Customs

v1.0.0 QBCore qs-inventory ox_inventory qb-inventory Lua 5.4

1 — Overview

DS Prison Creator allows server administrators to build fully functional jails and prisons directly in-game without touching any configuration files after initial setup. Every jail, cell, door, camera, outfit, and shop location is managed through a NUI admin menu.

Officers can book suspects, manage active sentences, escort prisoners, and view live CCTV feeds — all from the /sendjail NUI panel. Prisoners experience a real-time countdown HUD, yard time cycles, prison outfits, a canteen shop, and a commissary kiosk, with all data persisted to MySQL.

Every jail, cell, door, camera, outfit, canteen, commissary, check-in zone, and transport vehicle is configured entirely in-game through the /prisoncreator menu — no file editing required after initial setup.

3 — Installation

  1. Copy the ds_prisoncreator folder into your server's resources directory.
  2. Import sql/install.sql into your database. This creates all 22 required tables. The script is idempotent (CREATE TABLE IF NOT EXISTS) — safe to re-run.
  3. If upgrading from an older version, also run sql/update.sql.
  4. Add ensure ds_prisoncreator to your server.cfg.
  5. Open config.lua and add your FiveM identifier to Config.Admins.
  6. Optionally configure your Discord webhook URL(s) in Config.Logging.
  7. Restart the resource or reboot the server.

server.cfg Start Order

ensure qb-core
ensure oxmysql
ensure PolyZone
ensure ds_notify
ensure qs-inventory   # or ox_inventory / qb-inventory
ensure ds_prisoncreator

4 — Configuration — config.lua

All operator settings are in config.lua. After initial setup, day-to-day configuration is done via the in-game /prisoncreator menu.

Admins

Only players whose FiveM identifiers are in Config.Admins can open the /prisoncreator menu.

Config.Admins = {
    'fivem:XXXXXXX',        -- your FiveM identifier
    -- 'license:abc123...',  -- or a license identifier
}
The server console (src == 0) is always treated as an admin regardless of this list.

Commands

Config.SetupCommand    = 'prisoncreator'  -- opens admin creator menu
Config.SendJailCommand = 'sendjail'       -- officers use to book suspects

Inventory System

Config.InventorySystem = 'auto'
-- Options: 'auto' | 'ox' | 'qs' | 'qb'

'auto' detects the first running inventory (ox → qs → qb). Force a specific one if auto-detection picks the wrong resource.

General

Config.NearbyPlayerRadius15.0Metres — radius used to populate the /sendjail suspect dropdown.

Controls the global locked/unlocked door cycle. Set Enabled = false to keep all cells permanently locked for every sentence.

Config.DoorFreezeDistance = 3.0  -- metres; increase if doors flicker in large cells

Transport Vehicles

Vehicles available in the /prisoncreator Transpo tab dropdown. Add or remove entries freely.

Config.TransportVehicles = {
    { model = 'pbus',    label = 'Police Prison Bus'  },
    { model = 'policet', label = 'Police Transporter' },
    { model = 'riot',    label = 'Police Riot Van'    },
    -- add or remove entries freely
}

UI & HUD

Config.MenuTitle        = 'DS_CUSTOMS PRISON CELL CREATOR'
Config.TimerHudPosition = 'top-right'  -- prisoner sentence HUD position

Sentence Pause Reasons

Shown in the reason dropdown on each inmate card in /sendjail. Mark exactly one entry with isTransfer = true to enable the facility-transfer workflow.

Config.PauseReasons = {
    { code = 'COURT_TRANSPORT',  label = 'Court Transport'                        },
    { code = 'MEDICAL_HOLD',     label = 'Medical Hold'                           },
    { code = 'TRANSFER',         label = 'Facility Transfer', isTransfer = true  },
    -- add / remove entries freely
}

5 — Admin Setup Guide

Open the creator with /prisoncreator. The NUI menu is divided into tabs. Every change saves to the database immediately with no restart required.

Creating a Jail

  1. In the Jails tab, type a unique name and click Create Jail.
  2. A jail row appears. Expand it to access its sub-tabs: Cells, Doors, Cameras, Canteen, Commissary, Check-In/Out, Transpo, and Jobs.
  3. Set a Release Location — stand where released prisoners should spawn and click Set Release Location.

Drawing Cell Zones

  1. Expand a jail, go to the Cells sub-tab, enter a cell name, and click Draw Cell Zone.
  2. A 3D drawing tool activates. Use the controls below to trace the cell perimeter.
KeyAction
W / A / S / DMove the placement ball (camera-relative)
RMove ball up
QMove ball down
Shift4× speed modifier
MouseOrbit camera around the ball
ScrollZoom in / out
EPlace a point at the ball's current position
BackspaceRemove the last placed point
EnterFinish drawing (minimum 3 points required)
EscapeCancel

Place at least 3 points tracing the floor perimeter. Press Enter to save. The Z range is calculated automatically with ± padding from your placed points.

Assigning Cell Doors

  1. Under Cells, click Set Door on a cell row.
  2. A crosshair tool activates — aim at the door prop and press E to capture its coords and model hash automatically.
  3. Select the door animation type: door (swing), sliding, or garage.

Officer Doors & Terminals

Officer doors are facility-level doors that officers lock/unlock with E in-world. They persist their locked state in the database. Double doors are supported — select Double Door pair type and assign two door props sequentially; both always toggle together via a shared pair_id.

Available door types: door, double, sliding, doublesliding, garage

Terminals — physical kiosks in the world. Officers approach and press E to open a door control panel for that terminal. Doors can be assigned to a specific terminal or left unassigned (appears on all terminals for the jail). Add terminals via Doors tab → Add Terminal.

CCTV Cameras

  1. In the Cameras tab, enter a camera name and click Add Camera. Your current ped position and rotation are saved as the camera viewpoint.
  2. Officers view cameras through /sendjail → Cameras tab. Cycle with left/right arrows or A/D.

Prison Outfits

  1. Put on the desired outfit on your character, then go to the top-level Outfits tab and click Save Male Outfit or Save Female Outfit.
  2. A snapshot of every GTA ped component and prop value is saved as raw JSON — no clothing resource dependency.

When a prisoner is booked, the gender-appropriate outfit is applied. Their original clothing is saved to ds_prison_clothing_holds and fully restored on release.

Canteen & Commissary

Canteen — a shop where prisoners spend commissary funds:

  1. In the jail's Canteen tab, add items from the QBCore shared items list with a price.
  2. Add shop locations — stand at the in-world counter and click Add Location. Prisoners see a prompt within 3 metres.

Commissary — a kiosk where prisoners deposit cash into their account:

  1. In the jail's Commissary tab, add kiosk locations the same way. Commissary funds are global (not per-jail).

Check-In / Check-Out Zones

Automatically strips and restores visitor (non-prisoner, non-officer) inventories at prison entry/exit points.

  1. Draw a polygon zone in the Check-In/Out tab (same controls as cell zones).
  2. Set the type: Check-In strips items on entry; Check-Out restores items on entry.
Police job players are always exempt from inventory stripping in check-in zones.

Transport Vehicles

  1. In the jail's Transpo tab, select a vehicle model from the dropdown (populated from Config.TransportVehicles).
  2. Set the spawn point (where the van spawns) and the park point (where honking despawns it).

The van spawns server-side and is visible to all players. Honk at the park point to despawn it after dropping off the prisoner.

Police Jobs & Per-Jail Access

Global Police Jobs (top-level Police Jobs tab) — defines which QBCore jobs can use /sendjail at all. Changes reload the in-memory cache immediately.

Per-Jail Access (jail Jobs sub-tab) — defines which police jobs can access a specific jail's inmates, doors, cameras, and transport. An officer's job must appear in both lists.

Contraband / Confiscated Items

  1. In the top-level Confiscated Items tab, search for an item by name, set a penalty time, and click Add.

At booking, the prisoner's inventory is scanned. Contraband items are permanently destroyed and their penalty seconds are added to the sentence. All other items are stripped and held in ds_prison_inventory_holds, then fully returned on release. A Discord log embed is fired for each booking that finds contraband.

6 — Officer Guide — /sendjail

Open the booking menu with /sendjail. Your job must be in the Global Police Jobs list.

Booking a Suspect

  1. Click the Book tab.
  2. Select a suspect from the nearby players dropdown (within Config.NearbyPlayerRadius metres).
  3. Select a jail from the dropdown (only jails your job can access appear).
  4. Enter the sentence duration (hours / minutes / seconds).
  5. Click Send to Jail.

The server verifies access, finds a random unoccupied cell, scans for contraband, teleports the prisoner, applies the prison outfit, starts the countdown HUD, and logs to Discord.

Inmate Management

The Inmates tab shows all active sentences for jails your job can access.

ActionDescription
Extend / Reduce SentenceAdd or subtract time. The prisoner's HUD updates in real time.
Return to CellTeleport the prisoner back to their cell centroid. Optionally apply a per-cell lockdown override.
Early ReleaseImmediately release, teleport to the release location, and return all held inventory.
Cell Override (Escort)Unlock the prisoner's cell and disable containment checks for escorting. Toggle again to clear.
Hold SentencePause the countdown. Select a reason from Config.PauseReasons. The card shows a blue "SENTENCE PAUSED" banner.
Resume SentenceResumes the timer and extends release_at by exactly the pause duration so no time is lost.

Facility Transfer Workflow

  1. On the inmate card, select the isTransfer = true reason from the dropdown. A Target Facility dropdown appears.
  2. Select the destination jail and click ⏸ HOLD SENTENCE. The prisoner's timer pauses and escort mode activates.
  3. Transport the prisoner to the new facility.
  4. Open the Inmates tab and click ▶ RESUME SENTENCE. The server places the prisoner in the first available cell at the new jail, restores remaining sentence time, and logs the transfer.

History Tab

Search historical sentence records across all jails (shared criminal record — not scoped to your job's jails). Filter by player name and/or jail. Returns up to 100 most-recent records.

Warden Log

Accessible to the highest-grade officer of a job. Displays an audit trail of all officer management actions — early releases, sentence adjustments, cell returns, override activations — filterable by jail and date range. Returns up to 200 entries.

CCTV Viewer

The Cameras tab shows all cameras for your accessible jails. Click a camera to view a live feed via a scripted camera native. Cycle with left/right arrows or A/D. Press Escape or the Exit button to return.

7 — Prisoner Experience

Sentence Timer HUD

A real-time countdown is shown at Config.TimerHudPosition. The HUD displays:

  • Sentence time remaining (HH:MM:SS)
  • Current yard-time phase and time until the next cycle change
  • Jail and cell name
  • Escort mode indicator (when override is active)

The timer ticks entirely client-side using an anchor + elapsed time pattern. The server pushes the authoritative seconds on booking, resync, and any sentence adjustment.

Yard Time Cycle

The server runs a global 1-second loop alternating between locked and unlocked phases.

PhaseBehaviour
LockedCell doors are frozen shut. Prisoners outside their cell zone are snapped back automatically.
Unlocked (Yard Time)Cell doors open. Prisoners can move freely around the facility.
WarningLast WarningBeforeLock seconds of yard time. Prisoners receive a reminder every ReminderInterval seconds to return to their cell.

Cell Containment

Two containment loops run client-side at all times:

  • Prisoner containment (1 s): When the cycle is locked, if the prisoner is outside their PolyZone (with Config.CellReturnBuffer Z tolerance) and no escort override is active, they are teleported back to the cell centroid with a screen fade.
  • Universal containment (100 ms): For non-prisoners (officers, civilians) when the cycle is locked — if they enter a locked cell zone they are instantly ejected 2 metres past the cell door, making the boundary feel like a wall.

Canteen & Commissary

  • Canteen: Within 3 metres of a canteen location a prompt appears to open the shop. Items purchased deduct from the commissary balance.
  • Commissary kiosk: Within 3 metres of a kiosk a prompt appears to deposit cash. Cash is removed from wallet and added to the global commissary account.

Escort / Override Mode

When an officer activates Cell Override, a ds_prison_cell_overrides row is inserted, the prisoner's containment checks are disabled, and their cell door unlocks. When the override is cleared, the row is deleted and normal cycle rules re-apply.

8 — Visitor Check-In System

When a non-police player enters a check-in zone, all their inventory items are removed and saved to ds_prison_visitor_inventory. When they enter a check-out zone in the same jail, all items are returned and the hold record is deleted.

If a check-in zone is deleted by an admin, all held inventories for that zone are immediately returned to online players before the zone row is removed.

9 — Court Transport (Sentence Pause / Resume)

The transport system allows a prisoner's sentence timer to be frozen during court attendance, then resumed with release_at extended by exactly the pause duration — no time is lost.

Configure the transport van, spawn point, and park point for each jail in the Transpo tab of /prisoncreator.

While paused:

  • The prisoner's HUD timer freezes.
  • Their cell door unlocks automatically (a cell override row is inserted).
  • The transport is logged to Discord and the Warden Log.

When resumed:

  • The pause duration is calculated and added back to release_at via DATE_ADD.
  • The cell override is cleared and the door re-locks.
  • The prisoner's HUD resumes ticking.

12 — Developer API

These are server-side exports callable from any other resource on your server.

PauseSentence(citizenid, pausedBy) boolean, string

Pauses a prisoner's sentence timer. Idempotent — calling on an already-paused sentence is a no-op.

Returnmessage valueMeaning
true'paused'Sentence paused successfully
false'already_paused'Sentence was already paused
false'No active sentence found for ...'No active sentence for this citizenid
 
local ok, msg = exports['ds_prisoncreator']:PauseSentence('CITIZEN123', 'Judge Smith')
if not ok then print(msg) end

ResumeSentence(citizenid) boolean, string

Resumes a paused sentence, calculating the exact pause duration and extending release_at by that amount so no sentence time is lost.

Returnmessage valueMeaning
true'resumed'Sentence resumed successfully
false'not_paused'Sentence is not currently paused
false'No active sentence found for ...'No active sentence for this citizenid
 
local ok, msg = exports['ds_prisoncreator']:ResumeSentence('CITIZEN123')
if not ok then print(msg) end

MDT Integration (Net Event)

Any MDT or dispatch resource can open the booking menu for an officer without requiring them to type /sendjail:

-- Server-side — trigger on behalf of an officer by their server ID:
TriggerClientEvent('ds_prisoncreator:server:openSendJailForPlayer', officerServerId)

-- Or trigger as the officer themselves:
TriggerServerEvent('ds_prisoncreator:server:openSendJailForPlayer')
The same police job guard applies — if the triggering player's job is not in the global police jobs list, the event is rejected.

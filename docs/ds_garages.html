DS Garages

Overhauled garage system with live camera preview, ped attendants, and cinematic UI — by DS Customs

v1.0.2 QBCore qs-inventory ox_inventory qb-inventory Lua 5.4 Escrow

1 — Requirements

ResourceNotes
qb-coreRequired framework. Must start before ds_garages.
oxmysqlRequired for all database operations.
PolyZoneRequired for garage zone detection on the client.
qs-inventory or ox_inventory or qb-inventoryOne inventory must be running. Auto-detected at startup in that priority order.
LegacyFuel (or custom)Configurable via Config.FuelResource. Must expose GetFuel() / SetFuel().
ds_notify (optional)If running, used for notifications. Falls back to QBCore notifications automatically.

2 — Escrow & Open Files

DS Garages is protected with FiveM Escrow. The core scripts are encrypted and tied to your licence key. The following files are excluded from escrow — you have full access to read and edit them.

Open — editable by you

  • config.lua
  • locales/*.lua
  • garages/*.lua

Encrypted — Escrow protected

  • client/client.lua
  • client/valet_client.lua
  • server/server.lua
  • server/valet_server.lua
  • bridge/notify.lua
  • html/*
All day-to-day customisation — garage locations, class restrictions, prompt text, locale strings, and all global settings — lives entirely in the open files.

3 — Installation

Database Setup

Choose one SQL file from the sql/ folder based on your situation.

Fresh install — no existing player_vehicles table

Run sql/fresh_install.sql. Creates the full player_vehicles table with all required columns including lastgarage and persist_coords.

Existing server — player_vehicles already present

Run sql/update.sql. Safely adds the two columns ds_garages needs and back-fills historical data. Safe to run more than once.

-- sql/update.sql adds these two columns:
ALTER TABLE `player_vehicles`
    ADD COLUMN IF NOT EXISTS `lastgarage`
        VARCHAR(50) NULL DEFAULT NULL AFTER `garage`;

ALTER TABLE `player_vehicles`
    ADD COLUMN IF NOT EXISTS `persist_coords`
        JSON NULL DEFAULT NULL AFTER `lastgarage`;

Receipt Item (Vehicle Transfer)

If Config.AllowVehicleTransfer = true, add this item to your QBCore shared items file:

['vehiclereceipt'] = {
    name        = 'vehiclereceipt',
    label       = 'Vehicle Receipt',
    weight      = 0,
    type        = 'item',
    image       = 'vehiclereceipt.png',
    unique      = true,
    useable     = true,
    shouldClose = true,
    description = 'An ownership receipt for a vehicle.',
},
The item must be unique = true and useable = true. The item name must exactly match Config.ReceiptItemName (default: 'vehiclereceipt').

server.cfg Start Order

ensure qb-core
ensure oxmysql
ensure PolyZone
ensure qs-inventory   # or ox_inventory / qb-inventory
ensure LegacyFuel     # or your fuel resource
ensure ds_garages
ds_garages auto-detects whichever inventory resource is running. Only one needs to be active.

4 — Configuration — config.lua

All global settings live in config.lua, which is open and unencrypted.

Behaviour

5 — Garages — garages/*.lua

Every file inside garages/ is auto-loaded. Files populate Config.Garages with one or more garage definitions. This folder is fully open. Add, remove, or rename files freely.

Garage Entry Schema

Config.Garages['mygaragename'] = {
    -- Required
    label    = 'My Garage',
    type     = 'public',   -- 'public' | 'depot' | 'job' | 'gang' | 'house'
    category = Config.VehicleClass['car'],

    -- Spawn points (at least one required)
    spawnPoints = {
        vector4(222.02, -804.19, 30.26, 248.19),
    },

    -- Cinematic preview camera
    previewSpawn       = vector4(222.03, -804.2, 30.26, 248.2),
    previewCamera      = vector4(225.52, -808.75, 31.57, 30.77),
    previewCameraAngle = -15.0,

    -- Exit teleport
    exitTeleport = { enabled = false },

    -- Ped attendant
    usePed     = true,
    pedModel   = 's_m_m_autoshop_01',
    pedCoords  = vector4(215.25, -806.28, 30.8, 343.97),
    zoneRadius = 4.0,  -- optional, defaults to 2.0

    -- Map blip
    blip = {
        show   = true,
        name   = 'Public Parking',
        sprite = 357,
        color  = 3,
        scale  = 0.60,
    },
}

Garage Types

typeBehaviour
'public'Any player can retrieve their own vehicles.
'depot'Only impounded vehicles appear here. A fee is charged on release.
'job'Restricted to players with a matching job. Add job = 'police' to the entry.
'gang'Restricted to players with a matching gang. Add gang = 'ballas' to the entry.
'house'Requires the player to hold the house key via qb-houses.

usePed vs Zone Interaction

usePedTrigger
trueA ped spawns at pedCoords. Player interacts via prompt near the ped.
falseA PolyZone circle at coords. No ped. Player interacts on zone entry.

7 — Valet System

The valet system dispatches an NPC driver to deliver a garaged vehicle to the player's current location. Included by default and can be disabled if not needed.

Disabling the valet system

Remove these two lines from fxmanifest.lua and restart the resource:

-- client_scripts block:
'client/valet_client.lua',   -- remove

-- server_scripts block:
'server/valet_server.lua',   -- remove

Also remove 'RequestValet' from the server_exports block. All other garage functionality continues working.

Triggering valet from another resource

-- Server-side (from another server script)
local ok, err = exports['ds_garages']:RequestValet(source, plate)
if not ok then print('Valet failed:', err) end

-- Client-side (triggers the server via net event)
TriggerServerEvent('ds_garages:server:RequestValet', plate)

8 — Developer API

DS Garages exposes server exports, QBCore callbacks, and net events for use in other resources — phone apps, mechanic scripts, impound systems, dealerships, etc.

Server Exports

Call these from any server-side script in any resource.

RequestValet(source, plate) bool, string|nil

Dispatches a valet ped to deliver the player's garaged vehicle. Validates ownership and guards against duplicate requests internally.

okerrCodeMeaning
truenilValet dispatched successfully
false'invalid_player'Source is not a valid QBCore player
false'already_active'A valet is already running for this player
false'not_found'Plate not owned by the player, or vehicle not garaged
false'spawn_failed'Server entity failed to create
 
local ok, err = exports['ds_garages']:RequestValet(source, 'ABC1234')
if not ok then print(err) end

getAllGarages() table[]

Returns every garage in Config.Garages as a flat array. Useful for phone apps, maps, or external vehicle lists.

local garages = exports['ds_garages']:getAllGarages()
for _, g in ipairs(garages) do
    print(g.name, g.label, g.type)
end

getGarage(name) table|nil

Returns the raw config entry for a single garage key, or nil if not found.

local g = exports['ds_garages']:getGarage('pillboxgarage')
if g then print(g.label) end

getVehicleState(plate) table|nil

Looks up a vehicle by plate and returns its current database row. Returns nil if the plate is not found.

KeyTypeDescription
platestringPlate text (upper-cased)
citizenidstringOwner's QBCore citizen ID
stateCodenumber0 = out · 1 = garaged · 2 = impounded
stateLabelstring'Out' / 'Garaged' / 'Impounded'
garagestring|nilCurrent garage key, or nil if out
lastgaragestring|nilLast garage the vehicle was stored in
fuelnumberFuel percentage
enginenumberEngine health (0–1000)
bodynumberBody health (0–1000)
 
local info = exports['ds_garages']:getVehicleState('ABC1234')
if info and info.stateCode == 2 then
    print(info.plate .. ' is impounded')
end

setVehicleState(plate, state, garageKey) boolean

Directly writes state and garage for a vehicle. Does not validate ownership — caller is responsible for any auth checks. Ideal for impound systems and admin tools.

-- Impound a vehicle
exports['ds_garages']:setVehicleState('ABC1234', 2, 'depotLot')

-- Return a vehicle to a specific garage
exports['ds_garages']:setVehicleState('ABC1234', 1, 'pillboxgarage')

getPlayerVehicleCount(citizenid) number

Returns the total number of vehicles owned by a player. Returns 0 if none or citizenid is invalid. Useful for capping purchases at dealerships.

local Player = exports['qb-core']:GetPlayer(source)
local count  = exports['ds_garages']:getPlayerVehicleCount(Player.PlayerData.citizenid)
if count >= 5 then
    -- block the purchase
end

saveVehicleMods(plate, props) boolean

Writes a full QBCore.Functions.GetVehicleProperties() blob to the mods column. Full overwrite — replaces everything previously stored. Use mergeVehicleMods if you only need to update specific keys.

-- After a player installs parts (props collected client-side, sent to server)
exports['ds_garages']:saveVehicleMods(plate, props)

getVehicleMods(plate) table|nil

Returns the decoded mods table for a vehicle, or nil if none has been saved yet.

local mods = exports['ds_garages']:getVehicleMods('ABC1234')
if mods then print(mods.color1) end

mergeVehicleMods(plate, patch) boolean

Shallow-merges a partial table into the stored mods. Only keys in patch are changed — all other stored keys are preserved. Preferred for scripts that only manage a subset of vehicle data.

-- Paint shop — only colours change, performance mods untouched
exports['ds_garages']:mergeVehicleMods('ABC1234', {
    color1           = { 255, 0, 0 },
    pearlescentColor = 0,
})

-- Mechanic installs a turbo — only that key changes
exports['ds_garages']:mergeVehicleMods('ABC1234', { modTurbo = true })

QBCore Callbacks

Triggered from client-side scripts via QBCore.Functions.TriggerCallback.

Returns all vehicles owned by the calling player, enriched with labels and status strings. Intended for phone apps and external vehicle-list UIs.

QBCore.Functions.TriggerCallback('ds_garages:server:GetPlayerVehicles', function(vehicles)

    for _, v in ipairs(vehicles) do
        print(v.plate, v.stateCode, v.garage)
    end
end)

Net Events — Client → Server

ds_garages:server:RequestValet (plate)

Client-side equivalent of the RequestValet export.

TriggerServerEvent('ds_garages:server:RequestValet', 'ABC1234')

ds_garages:server:SetVehicleOut (plate)

Marks a vehicle as out (state = 0) and clears its garage field.

TriggerServerEvent('ds_garages:server:SetVehicleOut', plate)

ds_garages:server:SetVehicleIn (plate, garageKey)

Marks a vehicle as garaged (state = 1) and writes both garage and lastgarage.

TriggerServerEvent('ds_garages:server:SetVehicleIn', plate, 'pillboxgarage')

ds_garages:server:UpdateVehicleStats (plate, fuel, engine, body)

Writes current fuel, engine health, and body health to the database on vehicle park.

TriggerServerEvent('ds_garages:server:UpdateVehicleStats', plate, fuel, engine, body)

ds_garages:server:TrackVehicle (plate)

Requests the world coordinates of an out vehicle. Server fires ds_garages:client:TrackVehicle back to set a GPS waypoint. Requires Config.AllowVehicleTracking = true.

TriggerServerEvent('ds_garages:server:TrackVehicle', plate)

Net Events — Server → Client

ds_garages:client:StartValet (data)

Tells the valet client to begin the delivery sequence. Fired automatically by RequestValet — do not fire manually. Fields: netId, plate, mods, fuel.

ds_garages:client:ConfirmSpawn (data)

Tells the client to spawn the vehicle after depot payment is confirmed.

ds_garages:client:TrackVehicle (coords)

Delivers the vehicle's current world coordinates to the client. Used to set a GPS waypoint after a TrackVehicle server event.

10 — FAQ & Troubleshooting

Which inventory resource takes priority?

ds_garages checks in this order: qs-inventory → ox_inventory → qb-inventory → plain qb-core. The first running resource wins. Only one needs to be active.

Vehicles showing as Out after a server restart

If PersistentVehicles and AutoRespawn are both false, out vehicles are left in state=0 and assigned a depot fee. Enable AutoRespawn to return them to garages, or PersistentVehicles to re-spawn them at their last known coordinates.

persist_coords column missing error

Run sql/update.sql on your database. It adds the persist_coords JSON column required when Config.PersistentVehicles = true.

Receipt item is not working

Confirm the item is registered in QBCore.Shared.Items with unique = true and useable = true, and that Config.ReceiptItemName exactly matches the item's name key.

Vehicle class filter not working

Check Config.ClassSystem = true in config.lua and that the garage's category field references a valid Config.VehicleClass preset or a custom number array.

How do I add a job-restricted garage?

Config.Garages['policeparking'] = {
    label    = 'Police Parking',
    type     = 'job',
    job      = 'police',
    category = Config.VehicleClass['car'],
    -- ... spawnPoints, ped, blip
}

Valet ped not appearing

Ensure client/valet_client.lua and server/valet_server.lua are both in fxmanifest.lua and that 'RequestValet' is listed in server_exports. Restart the resource after any manifest changes.
